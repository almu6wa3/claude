## شرح المحتوى

MarkItDown أداة مجانية مفتوحة المصدر من Microsoft تحول ملفات PDF و Word و Excel و PowerPoint وحتى روابط YouTube إلى نص Markdown نظيف يفهمه الذكاء الاصطناعي بسهولة.

عندما ترفع ملفا مباشرة إلى Claude، يعالج النموذج كل عناصر التنسيق فيه من عناوين وتذييلات وهوامش، وهذا يستهلك آلاف الـ tokens لكل صفحة.

تحويل الملف إلى Markdown أولا يخفض هذا الاستهلاك بنسبة قد تصل إلى 70 بالمئة، وغالبا يعطيك إجابات أدق لأن النموذج يقرأ محتوى نظيفا بلا ضجيج.

## طريقة الإعداد

الأداة نفسها مجانية، لكن طريقة الإعداد هذه تتم عبر Claude Code، وهو متاح في خطة Claude Pro أو أعلى وغير متاح في الخطة المجانية.

1. افتح Claude Code على جهازك.
2. الصق هذا الطلب كما هو واضغط Enter:

   > ثبت لي أداة MarkItDown من هذا الرابط، وتأكد أن كل ما تحتاجه مثل Python مثبت عندي وثبته إذا لم يكن موجودا، ثم جهزها حتى أستطيع أن أطلب منك تحويل أي ملف إلى Markdown بطلب عادي:
   > https://github.com/microsoft/markitdown

3. اتركه يعمل. سينزل الأداة ويثبت كل ما تحتاجه نيابة عنك. إذا سألك سؤالا، أجبه بلغتك العادية.
4. إذا طلب منك إعادة التشغيل، أغلق Claude Code وافتحه من جديد.

**للاستدعاء:** ضع الملف في المحادثة مع Claude Code واكتب: حول هذا الملف إلى Markdown.

**للتحقق من نجاح الإعداد:** جرب ملف PDF صغير، إذا رجع لك النص محولا إلى Markdown فالإعداد نجح.

## جولة في المزايا

- **تحويل ملفات Office:** يحول Word و Excel و PowerPoint مع الحفاظ على العناوين والقوائم والجداول والروابط، تستخدمه عند إدخال مستندات عملك إلى الذكاء الاصطناعي.
- **تحويل PDF:** يستخرج النص والبنية من ملفات PDF الرقمية، لكن ملفات PDF الممسوحة ضوئيا وهي مجرد صور لا يخرج منها نص.
- **روابط YouTube:** أعطه رابط فيديو وسيجلب لك نص الفيديو كاملا جاهزا للتلخيص أو الترجمة.
- **الصور:** يستخرج البيانات الوصفية للصورة.
- **الملفات الصوتية:** يحول الكلام المسجل إلى نص مكتوب.
- **صيغ الويب والبيانات:** يدعم HTML و CSV و JSON و XML وملفات ZIP وكتب EPub، مفيد لأرشفة صفحات الويب ومعالجة ملفات البيانات.

## طرق لاستخدامه بشكل يومي

اجعل تحويل الملفات إلى Markdown عادة ثابتة قبل رفعها لأي أداة ذكاء اصطناعي. من الأمثلة العملية:

- **تلخيص تقرير طويل:** ضع التقرير في Claude Code واكتب: حول هذا الملف إلى Markdown ثم لخصه في 10 نقاط رئيسية مع أهم الأرقام.
- **تلخيص فيديو YouTube بدون مشاهدته:** الصق رابط الفيديو واكتب: حول هذا الفيديو إلى نص ثم أعطني أهم الأفكار في نقاط.
- **ملف تستخدمه كثيرا:** حوله مرة واحدة إلى Markdown واحفظ الناتج، ثم ارفع ملف الـ md بدلا من الملف الأصلي في كل محادثة جديدة.

## نصائح متقدمة

- أشهر خطأ هو تحويل PDF ممسوح ضوئيا وهو مجرد صور وتوقع الحصول على نص، والحل رفع الصور مباشرة إلى Claude.
- لا تتوقع أن يحافظ Markdown على التصميم البصري، فهو يحفظ البنية فقط من عناوين وقوائم وجداول، وراجع ناتج التحويل سريعا خصوصا الجداول المعقدة قبل إرساله.
- إذا كنت تستخدم تطبيق Claude Desktop أيضا، اطلب من Claude Code أن يربط MarkItDown به، حتى يحول Claude الملفات بنفسه أثناء المحادثة هناك أيضا.
- إذا توقف شيء عن العمل، اطلب من Claude Code أن يصلحه، فهو من ثبت الأداة ويعرف أين وضع كل شيء.
